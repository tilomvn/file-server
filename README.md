# Environment Requirement
* Must have Java 8 or above.
# How to build and run
* Type command [mvnw verify] to build.
* Go to directory target, type command [java -jar file-server.jar "path of directory" ] to run.
# Deployment
* The application's architecture is client-server architecture, so when you run it on different machine
 with client, must update server address of client application.
* By default the client and server will run in same machine.
